## Wording check

- Only the shard is a link: "delete that link or file" points at the shard. Right. The log is an audit trail, so
  deleting a planted link loses nothing real.
- `.project-log` itself is a link or a file: the text says ".project-log ... is a link", and "that link or file" is
  that link, not the folder's contents. Right. It no longer says "remove the planted file in .project-log/".
- Low finding (not a blocker): when `.project-log` is a link to a folder, `ls -la .project-log` follows the link and
  lists the target's contents, so it does not show the link. `ls -ld .project-log` does. The hint is right for a
  planted shard and weak for a planted folder link.
- A user with a deliberate `.project-log` symlink is told to delete it. That follows from the refusal the PM accepted
  in bug 54b4e811; the text is accurate about the cause.
