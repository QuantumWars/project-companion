`roadmap.json` inside a `.project` folder would then be read as the project's roadmap. I added
`tests/qa-49c078ce-gate.test.ts` (1 test, no child process, no FIFO, temp HOME, temp folder removed). It passes on the PR

## E2E limit (not a defect in the fix)

On the pre-fix build, scenarios (a) and (c) already returned fast with "No .project". I also ran 13 other commands
(`status`, `flow`, `next`, `drift`, `feature list`, `phase list`, `review`, `whose`, `wip`, `card list`, `update`,
`gate status`, `verify`) against a `.project` folder with a FIFO roadmap on the pre-fix build: all returned (exit 1). So no
CLI command I tried reaches the hang or the outside write; the CLI stops earlier. The library-level tests (7 of 7 plus my
test) are the proof for (a) and (c); the e2e only proves no regression there. The older-layout FIFO (b) is the case the
CLI reaches, and the e2e shows it hangs before the fix and returns after. Other entry points (the web app, the MCP
server, the notify path) were not run.
