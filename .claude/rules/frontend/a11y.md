# Frontend rules: accessibility (WCAG 2.2 AA basics)

1. Every action works with the keyboard alone, in a sensible order.
2. Focus is always visible.
3. Every image that carries meaning has alt text. Decorative images have `alt=""`.
4. Every form field has a visible label, and every error says how to fix it.
5. Text contrast meets WCAG 2.2 AA: 4.5:1 for normal text, 3:1 for large text (WCAG 2.2, success criterion 1.4.3).
6. Do not use colour as the only signal.
